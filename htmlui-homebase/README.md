# Interface van HomeBase Back-up

Deze map vervangt de module `github.com/kopia/htmluibuild` (zie de `replace` in `../go.mod`).
`build/` is de gebouwde interface uit de fork van htmlui (branch `homebase`). Bijwerken:

```bash
../homebase/build-htmlui.sh   # bouwt ../../htmlui en kopieert de build hierheen
```
